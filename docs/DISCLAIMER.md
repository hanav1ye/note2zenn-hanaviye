# 免責・利用者の責任

本ツール（note2zenn）を利用したことによって生じる**あらゆるトラブル・損害・不利益**は、**すべて利用者（使用者）の責任**に帰属します。

提供者は、次のいずれについても**保証しません**。

- 変換結果の正確さ・品質・完全性
- 公開した記事の内容・著作権・利用規約への適合
- OpenAI・note・GitHub など第三者サービスの動作・料金・障害
- データの消失・漏えい・誤った `git push` による影響
- API 利用料金・ディスク容量・処理時間

## 利用者が負う判断・運用

次は**利用者自身**が確認・判断・対応してください。

| 項目 | 内容 |
|------|------|
| 設定 | Zenn リポジトリのパス、API キー、Git トークンなどが正しいこと |
| 変換元 | 指定した note URL の記事を変換してよい権利があること |
| 公開前 | 生成された Markdown・画像・コミット内容を目視で確認すること |
| 秘密情報 | キーやトークンがログ・スクショ・誤コミットで漏れないこと |
| 外部送信 | 記事本文が OpenAI API に送られることへの同意と社内ルールの遵守 |

## 想定している使い方

- 自分の PC の VSCode / Cursor 上で、**自分が内容を把握している note 記事**を変換する
- テスト用または意図した Zenn 用リポジトリを `zennRepoPath` に指定する
- `git push` する前に差分を確認する

## 想定していない使い方

- 他人の記事を無断で変換・公開すること
- 内容を確認せず本番リポジトリへ push すること
- 社内秘・個人情報を、許可なくクラウド LLM に送ること
- 本ツールをサーバとして公開し、不特定多数に使わせること

## データの送信先（参考）

| 操作 | 送信先 |
|------|--------|
| 本文リライト | OpenAI API（記事本文など） |
| 記事・画像取得 | 入力した URL および HTML 内の画像 URL |
| GitHub Token 設定時 | GitHub（HTTPS push の認証） |
